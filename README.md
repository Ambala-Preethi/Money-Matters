# Money Matters – Personal Expense Tracker

A responsive personal finance management application built using React. Money Matters helps users track their income and expenses, monitor their balance, and understand their spending habits through a simple dashboard.

## Features

- **Financial Dashboard:** View total balance, income and expenses.
- **Transaction Management:** Add, edit and delete transactions.
- **Transaction Filters:** Filter by income, expenses and categories.
- **Search:** Find transactions using titles, notes or amounts.
- **Spending Analytics:** View weekly income and expense comparisons.
- **Category Breakdown:** Understand spending across different categories.
- **Responsive Design:** Works across desktop, tablet and mobile screens.
- **Data Persistence:** LocalStorage fallback when an external API is unavailable.
- **User Feedback:** Loading, success, empty and error states with toast notifications.

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/Ambala-Preethi/Money-Matters.git
```

2. Navigate to the project directory:

```bash
cd Money-Matters
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.

## Production Build

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
